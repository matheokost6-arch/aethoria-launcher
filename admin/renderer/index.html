Launcher admin

Connexion au serveur par RCON. Réservé à l’équipe d’administration.

Mot de passe mémorisé sur ce PC : laisse vide pour l’utiliser.

Activer RCON sur le serveur
  1. Dans le panel de l’hébergeur, ouvre server.properties.
  2. Mets enable-rcon=true, choisis rcon.port (souvent 25575) et un long rcon.password.
  3. Vérifie que l’hébergeur ouvre ce port, puis redémarre le serveur.

RCON n’est pas chiffré : n’administre jamais depuis un Wi-Fi public.
